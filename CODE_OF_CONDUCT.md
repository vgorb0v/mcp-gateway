# Code of Conduct

## Our Pledge

We aim to make MCP Gateway a welcoming, practical project for people improving local MCP tooling. Be respectful, direct, and constructive.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and experience levels.
- Keep feedback focused on the work and its impact.
- Accept maintainers' decisions about scope, safety, and project direction.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Publishing private information without permission.
- Repeated off-topic or bad-faith participation.
- Encouraging unsafe use of secrets, browser profiles, or local services.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; or restrict participation when behavior harms the project. Report concerns through GitHub project channels.
